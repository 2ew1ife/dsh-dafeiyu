# 来源与改动范围

本目录来源于 [KylinQ01/dsh-startup-animation](https://github.com/KylinQ01/dsh-startup-animation)，上游提交 `8edc4c7957549d8a210e27575413750238d715ab`。

启动动画实现、图片与配置管理、设置界面、壁纸行为由 KylinQ01 创作，遵循本目录保留的 MIT 许可证。这个衍生版仅增加黑红金配色、时钟刻度环、透明角色展示、深色壁纸支持和 DSH 0.2 插件详情配置入口；默认问候语和默认图片改为狂三主题。

桌宠本体仍是 [QCYTSN/dsh-dafeiyu](https://github.com/QCYTSN/dsh-dafeiyu)。本目录不将上游主体实现记为本次作者的原创。
